# Country Capitals Quiz

This is a simple quiz game that lets you enter the capital of a country.  
Each correct answer increases your score.

## Features
- Enter capital names
- Score increases for each correct answer
- Fun way to learn geography

## How to Play
1. Start the game.
2. Country name is displayed.
3. Enter the capital of that country.
4. If it's correct, your score increases!
